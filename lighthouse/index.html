Needs attention first

  • The homepage is very heavy: about 16 MB. Oversized images are the main cause. Lighthouse estimates 2.1 MB could be saved on a phone by delivering images properly.
  • The phone test shows the main content taking 20.8 seconds on a slow phone and network, and the speed score is 55 out of 100.
  • The page has no meta description and several images have no alt text. Both hurt Google search and screen-reader users.

What to fix

The biggest causes found by Lighthouse, in plain language, in the order we would tackle them.

Speed

  • Shrink and properly size images. Saves about 2.1 MB on a phone and 1.6 MB on desktop. The main banner image is the largest item on the page.
  • Send less JavaScript. Unused code of about 425 KB on a phone (555 KB on desktop) is downloaded and run for nothing.
  • Stop the page from being blocked while it loads. The phone spends 5.0 s of busy time on the main thread, and scripts and styles delay the first paint by 210 ms.
  • Cache files for longer (about 216 KB saved on repeat visits), and remove about 74 KB of unused styles.
  • Give every image a set width and height so the page layout is stable.

Search, access and tidiness

  • Add a meta description. The earlier SEO report also found meta tags were planned and never shown as done. Quick win
  • Add alt text to images. This helps Google Images and shoppers using screen readers.
  • Fix accessibility basics: links without a readable name, buttons and taps that are too small or too close, and headings out of order.
  • Clear browser errors. Errors and issues are being logged in the browser's console.
  • Forms for AI tools: 12 forms lack the extra labelling AI assistants use. Low priority.

Suggested next steps

  • Compress and resize the homepage images, and load only the first banner straight away. Do first
  • Add the meta description and image alt text. These are small changes with a clear search benefit.
  • Remove unused scripts and styles, and delay what is not needed on first view.
  • Check hosting and caching to speed up the server's first response.
  • Run the test again after the changes and before the festive and wedding season, and keep the scores in the next report.

How sure are we?

  • Scores come from a single Lighthouse run on 8 October 2026 and can change by a few points between runs.
  • Only the homepage was tested. Product and sale pages may behave differently.
  • The saving figures are Lighthouse's estimates, not guarantees.
